# Mucronix Reviews — star ratings and reviews for Joomla 6 and YOOtheme Pro

A free reviews extension for Joomla 6: star ratings and text reviews, made to work natively with YOOtheme Pro — with a builder element, dynamic fields and a source for grids. It works with any Joomla template.

- Ratings from 1 to 5 stars and, if wanted, a text. Each user can leave one review for each object and edit it later, if the options allow it.
- Only users in the groups you choose can rate. Guests can see ratings and published reviews.
- Three moderation modes: moderate all new reviews, only reviews with text, or none. Links in reviews can be allowed, sent for moderation or forbidden.
- Email notifications to moderators when a review is waiting for moderation.
- Ratings in the Schema.org markup generated by Joomla.
- English, Russian and Ukrainian.

Package: `pkg_mucronixreviews` with the component `com_mucronixreviews` and the plugins `plg_system_mucronixreviews` and `plg_content_mucronixreviews`.

## Download

- Latest release: https://github.com/mucronix/pkg_mucronixreviews/releases/latest

Sites with the package installed are notified about new versions in **System → Update → Extensions**.

## Requirements

- Joomla 6.0 or later
- PHP 8.3 or later
- MySQL or MariaDB
- YOOtheme Pro 5 for the builder element and dynamic fields (optional)

## Installation

1. Install the ZIP file in **System → Install → Extensions**. Both plugins are enabled automatically.
2. Open **Components → Mucronix Reviews → Options** and choose who can rate, how reviews are moderated and where they appear.

## Where the reviews are shown

**Under Joomla articles.** On the **Joomla Articles** tab, choose the categories. The review block — summary, form and reviews, or a smaller selection — appears above or below the text of articles in those categories.

**Shortcodes.** Use a shortcode in an article, in a Custom module with **Prepare Content** enabled, or in a YOOtheme Pro builder element:

| Shortcode | Shows |
|---|---|
| `{mucronixreviews}` | The summary, form and reviews for this article |
| `{mucronixreviews summary}` | The summary for this article |
| `{mucronixreviews id=123}` | Everything for article 123 |
| `{mucronixreviews summary id=123}` | The summary for article 123 |

A paragraph that contains only a shortcode is replaced entirely, so no empty paragraph is left. The full block is shown only once per article on a page, while the summary can appear more than once. In article lists and blog views, a shortcode displays only the summary.

**YOOtheme Pro.** The **Mucronix Reviews** element can display the summary, the summary with the reviews, or the full block with the form. It uses the article on the current page, or the article specified by **Object ID**. The dynamic content provides rating fields for each article — **Stars (Summary)**, **Average Rating**, **Number of Ratings** and more — plus a **Reviews** source for grids. Builder templates do not automatically display the review block below an article; add the element where you want it. In blog views, display the stars using **Stars (Summary)** or the element. Do not use a shortcode in the intro text for this: YOOtheme Pro shortens the intro text's HTML.

## Moderation

Reviews waiting for moderation appear in **Components → Mucronix Reviews → Pending**, with the number of pending reviews shown beside the menu item. A moderator can publish or reject a review, mark it as spam, or move it to the trash. Reviews in the trash can be permanently deleted.

**Notify Moderators** sends an email when a review is awaiting moderation. Notifications go to members of the selected groups who are allowed to moderate reviews and have **Receive System Emails** enabled, as well as to up to ten additional addresses. **Most Emails per Hour** limits the number sent. Email text is managed in **System → Mail Templates**. If an email cannot be sent, the review is still saved. When **Logging** is enabled in Global Configuration, the reason is written to the log under the category `com_mucronixreviews`, or when everything is logged.

## Schema.org

On the **Schema.org** tab, choose which object types should have their ratings added to the markup generated by Joomla. The **System - Schema.org** plugin must be enabled. A rating is added only for the object on the current page, and only when that rating is displayed on the page. Google does not show stars for ordinary articles, so this option is disabled for articles by default.

## Stored data

| Table | Holds |
|---|---|
| `#__mucronixreviews_reviews` | The object, user ID and username, rating, review text, state and dates |
| `#__mucronixreviews_stats` | The number of ratings and reviews, and the average rating for each object |

No IP address or author email address is stored. When a user is deleted, their reviews are either kept under the stored username or deleted, depending on the **When a User Is Deleted** setting.

## Uninstalling

Only the complete package can be uninstalled. If **Keep the Reviews When Uninstalling** is set to Yes (the default), the tables are kept and the reviews are available after reinstalling the package. If set to No, all reviews and ratings are permanently deleted. The options and email templates are deleted in either case.

## Building from the source

PowerShell 5.1 or later and PHP 8.3 are required:

    powershell -ExecutionPolicy Bypass -File build.ps1 -Php <path to php>

The build creates `build/pkg_mucronixreviews-<version>.zip`. The same source produces the same archive byte for byte. The checks in `tests/` are not included in the package; see `tests/stand/README.md` for instructions on running them.
